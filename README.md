# WordLearner B/S 开发版

这是独立的浏览器／服务器工程，当前版本 **0.2.15**。原桌面项目保持原位；Web 服务运行时不读取桌面数据库或配置。桌面数据库和服务配置均通过显式迁移工具一次性复制，迁移后仍保持数据目录隔离。

已对照桌面源码和运行补丁完成本轮模块审核、修复与自动化回归。功能覆盖、测试证据及仍有差异的项目见 [逐模块审核](docs/PARITY_AUDIT.md)。这不代表已完成所有设备、弱网环境和像素级一致性验收。

## 启动

本机依赖已安装，前端已构建。双击 `Start.cmd`，或在本目录执行：

```powershell
.\scripts\Start.ps1
```

打开 <http://127.0.0.1:8765>。按 `Ctrl+C` 停止服务。修改前端后使用 `scripts\Start.ps1 -Build`。

换一台电脑时安装 Python 3.12+、Node.js 22.12+，然后执行：

```powershell
.\scripts\Setup.ps1
.\scripts\Start.ps1
```

默认仅绑定本机回环地址，当前是一名学习者、一个服务进程。生产环境可通过显式环境变量启用反向代理部署；公网入口仍须提供 HTTPS 和访问认证。多人身份和多人并发学习尚待开发；单用户的未完成游戏由最后打开的页面自动接管。

## 已接通的功能

- 词库录入、去重、编辑、搜索、日期筛选、勾选、批量归档、浏览器发音。
- 单词分类标签；当前提供“初二上”。一键复习可选“全部词库”或“初二上”，默认保持全部词库模式；分类范围单独保存当天75词清单，计时和每日奖励上限仍共用真实记录。
- 普通打字练习；服务器维护下落、轮次、生命、输入判定和累计分数。只有服务端确认字母正确后才显示子弹，弹道指向实际命中的词条。
- 一键复习的每日清单、规则冻结、语音锁定、编号提示、重试上限、每日 30 分钟和奖励计算；可以持续多轮，不再因奖励槽位已满而禁止进入或自动结束。
- 免麦克风复习：同样不限轮次，跳过朗读锁定；实际键盘输入仍计入正式历史、总分、计时、奖励和结算邮件。
- 服务器保存游戏快照；刷新后返回主页点击「恢复进度」。最后打开或发起练习的页面自动接管未完成游戏，旧页面立即退出；切换练习模式时关闭其他遗留快照，已确认的学习记录、分数和奖励保持不变。
- 家长密码、单词数／轮数／奖励设置；规则按当天会话隔离，不修改全局计分常量。
- 每日统计、历史、掌握度、记忆趋势、操作日志和结算事件查看。
- 一键复习或免麦克风复习保存返回后，自动下载本场完整单词清单，文件名为 `当天单词记录YYYYMMDD.xlsx`；浏览器下载目录设为 `D:\` 时可直接保存到 D 盘根目录。
- AI 学习卡、批量卡片、录入检查、错词提示、问答、报告总结及缓存的调用接口。
- 启动、每 5 分钟、正常停止时，通过 SQLite backup API 保存独立备份，保留最近 40 份。

保存词条后自动生成学习卡并检测录入；进入游戏前以最多 4 个受控并发检查学习卡，短暂服务故障自动重试，最终失败仍不会开始游戏。次日预热、持久任务队列和邮件发送／失败重试已实现。邮件需明确启用 `email.enabled`；默认关闭。本机 AI 和 ASR 已通过真实服务测试。

## 导入单机版数据库

必须先关闭单机版并停止 B/S 服务，再运行一次性迁移：

```powershell
.\.venv\Scripts\python.exe -m backend.desktop_import `
  "C:\Users\Administrator\Downloads\words.sqlite3" `
  ".\data\wordlearner-web.sqlite3" `
  --archive-dir ".\data\imports"
```

迁移工具先备份 B/S 正式库，并将单机库保存为完整 SQLite 归档；随后合并词库和单词状态，导入学习历史、错字、累计积分、每日复习实际用时、奖励轮次、操作日志、邮件结算及 AI 缓存。旧版整站／整软件打开时长仍按来源保存在设置归档中，但不用于“累计复习”统计。相同单词按 `word_key` 合并，已有 B/S 记录保留。来源标签和 SHA-256 写入 `migration_imports`，同一来源重复运行只返回已有结果；来源内容发生变化时拒绝直接重复导入，避免历史重复。

单机版未完成游戏快照的格式与 B/S 会话不同，因此只保存在完整原库归档中，不替换正在进行的 B/S 会话。旧邮件事件使用 `desktop_*` 状态导入，邮件工作线程不会重新发送历史邮件。

## 导入教材分类词表

先把教材工作簿的总表抽取为去重后的 JSON，再在停止正式服务后执行带审计的导入。导入工具会先备份数据库，已有单词只补空释义或空音标并增加标签，不改学习次数、正确数、复习日期、计时、积分、奖励、历史和结算记录。

```powershell
python scripts\extract_textbook_xlsx.py "教材单词表.xlsx" ".\data\imports\grade8-upper.json"
.\.venv\Scripts\python.exe scripts\import_tagged_words.py `
  --database ".\data\wordlearner-web.sqlite3" `
  --input ".\data\imports\grade8-upper.json" `
  --source-file "教材单词表.xlsx" `
  --source-label "教材单词表.xlsx" `
  --tag grade8_upper `
  --backup-dir ".\data\backups"
```

相同英文按大小写、空格、Unicode 形式和英文撇号规范化去重。重复执行不会重复创建单词。每次导入均记录来源 SHA-256、实际数量和操作日志。

## 配置 AI、语音和查词

复制 `config.example.json` 为本目录的 `config.json`，填写后重启服务。不要覆盖原项目的 `ai_config.json`。

- `ai.base_url`：兼容服务的根地址，沿用原 AI 类的 `/v1/chat/completions` 拼接规则，不要重复带 `/v1`。
- `asr.base_url`：兼容 ASR 服务地址，末尾可以包含 `/v1`，请求追加 `/chat/completions`。
- 每组独立填写 `model`、`api_key`。
- 普通查词使用有道词典，释义及音标无需私钥；`translation.app_id`、`secret_key` 是可选的百度翻译增强。
- `email`：SSL SMTP 配置，`enabled` 默认为 false。发送结果不确定的任务不会自动重复发送。

配置只在服务器读取，不返回浏览器。普通练习、一键复习和免麦克风复习均沿用原版的 AI 学习卡前置检查；只有语音方式的一键复习需要 ASR 配置。浏览器麦克风需授予权限；本机地址属于可用的安全上下文。录音仅在内存传递，不写磁盘。复习画面底部可选择浏览器暴露的输入设备，并显示设备名、实时音量、采集时长、音频帧数、上传大小和识别原文；浏览器会记住上次成功设备。

## 结果真实性和本阶段行为差异

- 浏览器只提交输入、速度、提示、重试等动作，不能提交时长、分数、正确率或奖励结果。
- 服务器单调时钟测量运行时长；断线、隐藏页面、录音及提示暂停不增加有效学习用时。断线发现上限约 5 秒，尚不能保证与桌面壁钟时间逐毫秒一致。
- 操作编号去重；确认过的输入、答案历史、累计分数与快照在同一数据库事务提交。
- 每次真实轮次尝试都追加保留，最高奖励从记录中计算，不覆盖较差尝试。
- 免麦克风复习与语音复习共享当天清单和未完成会话，两种模式都可持续多轮；`round_count` 只定义奖励槽位。记录来源保留为 `debug`，用于审计输入方式。追加轮次会留下实际奖励尝试并竞争各奖励槽位的最高成绩，每日奖励积分和金额仍受家长设置上限约束。
- 主界面“累计复习”直接汇总每天已落库的一键复习有效游戏时间，并以小时:分钟:秒显示。语音和免麦克风复习均计入；普通练习、页面停留、断线、隐藏页面、录音和提示暂停均不计入。页面状态刷新不会增加时长。
- 「清零总分」保留外观但禁用；「删除」采用归档并保留历史。这两处是针对当前完整性约束明确披露的差异。
- 返回词库后可以增删改词；恢复复习时重新同步当天必选新词和旧词清单，保留已经发生的学习记录。游戏连接中、学习卡准备中禁止另一个页面修改词表。
- 主动退出复习按原规则占用一次本轮重试；断线／刷新恢复不占用。录音／提示有服务器超时保护。
- 页面接管只转移未完成会话的控制权，不增加重试、得分、奖励或历史记录；旧页面收到服务端失效通知后自动返回词库。
- 固定逻辑画布 980×574 并缩放显示；尚未完成不同窗口尺寸下的像素与动画逐项对照。

## 单人公网部署

仓库提供多阶段 `Dockerfile` 和资源受限的 `docker-compose.prod.yml`。正式域名使用 `words.rfdsx.online`，应用只加入服务器内部 Docker 网络，不发布主机端口；现有 Nginx 负责 HTTPS、Basic Auth 和 WebSocket 转发。配置、SQLite 数据、备份和证书均被排除在 Git 之外。具体步骤和入口配置见 [部署说明](docs/DEPLOYMENT.md)。
