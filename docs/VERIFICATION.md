## 页面自动接管

每个标签页使用独立的随机页面标识。页面打开时声明当前控制权；若另一标签页或浏览器仍连接同一场未完成游戏，服务端先保存已确认状态，再以专用 WebSocket 关闭码使旧页自动返回词库。接管只更新会话所有者和操作日志，不提交输入、不增加重试，也不改动得分、奖励或历史记录。后端测试逐字段比较接管前后的序号、得分、奖励、处理进度和历史总数；双标签页 Playwright 流程验证旧页自动退出、新页可恢复。

## 子弹命中与方向

旧前端在每次按键时立即画子弹，并用活动词列表最后一项作为目标，因此错键也发射，正确键也可能射向别的词。现由服务端完成字符判定后，仅在 `HitEvent` 上随确认回执返回实际命中的 `runtime_id`；错误输入和重复序号不返回命中。前端按该编号读取对应词条最后一帧的归一化画布坐标后再发射，最后一个字母使词条从状态中移除时仍能保持正确方向。浏览器回归同时验证错键零弹道，以及正确键弹道与目标词条中心在同一射线上；服务端单测验证正确目标和重放不重复发射。该变化只修正视觉反馈，不改变输入事件、计分、正确率、奖励或历史。

## 单机数据库迁移

迁移器只读打开桌面库，先检查 SQLite 完整性并计算 SHA-256；B/S 目标库先通过 SQLite backup API 备份。单机库另存完整归档后，所有转换在单一事务内执行，并写入 `migration_imports` 和逐词 ID 映射。累计总分以单机库保存的 `total_score` 原值写成带来源的迁移积分事件；使用时长按两个系统互不重叠的实际记录相加。重复运行同一来源不会重复增加数据，来源文件变化则停止并要求重新审核。

用户确认的最新 69.82 MiB 单机库已在隔离 B/S 副本完成全量演练：来源 1,178 个词、10,846 条学习历史、1,303 条错字、134 条奖励轮次、128,174 条操作日志、95 条结算邮件事件和 3,941 条 AI 缓存全部转换成功；其中与测试 B/S 库重复的 1 个词按键合并。迁移后 SQLite `integrity_check=ok`、外键检查为空，B/S 可读取 1,181 个合并词、10,867 条历史记录、128,205 条操作日志和 97 条结算事件；以相同来源再次执行会返回 `already_imported`，不会重复累加。旧规则样本 2026-07-15 保持 99/100 分对应 ¥4.95，新规则样本 2026-09-27 保持 197/400 分对应 ¥1.97。单机未完成游戏状态保留在完整归档中，不替换 B/S 当前会话。
