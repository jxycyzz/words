## 麦克风识别诊断栏

复习画面最底部固定显示麦克风状态。每次朗读会依次显示打开设备、实时音量、采集时长和帧数、上传识别，并在返回后显示当前输入设备、ASR 原文、服务端实际收到的音频大小和锁定／失败原因。可选择浏览器暴露的麦克风，成功设备保存在当前浏览器；拔插设备时自动刷新列表。识别为空、浏览器无权限、无设备、设备占用、没有真实音频帧和服务错误使用不同提示。免麦克风模式提供“按住测试麦克风”，只显示识别结果，不建立语音锁定。识别原文只随本次响应显示，不写入学习历史、操作日志、报告或结算数据。

新增 API 测试验证识别原文、规范化文字、音频字节数、匹配标志和锁定状态均来自服务端；浏览器回归将 `getUserMedia` 故意延迟 450 ms，并在 70 ms 时松开空格，验证页面继续等待设备、取得真实帧、上传 WAV、显示 `voiceword` 并正确锁词，复现并覆盖原故障。另用浏览器流程验证免麦克风模式只诊断采音，不锁词、不计分、不新增学习历史。诊断显示不改变输入、得分、正确率、奖励和历史；录音期间沿用原暂停机制，不把诊断时间计入学习时长。

## 连续语音识别延迟优化

正式使用记录显示从 `voice_start` 到锁词通常为 2～5 秒，其中包含用户按住空格的实际朗读时长。服务器访问日志同时显示每个词都会重新请求 Worklet，源码审核确认浏览器此前每次都重建麦克风流和 AudioContext，服务端也每次创建新的 ASR HTTP 会话。0.2.10 在同一游戏页面内复用浏览器采集通道，并在 60 秒无语音、失焦、离开页面或切换设备时释放；服务端缓存同一 ASR 客户端以复用 TLS／HTTP 连接。底部诊断栏新增设备启动、服务识别和总响应耗时。浏览器回归连续识别两个词并断言 `getUserMedia` 只调用一次，第二次设备启动在测试环境约 12 ms；服务端单测确认连续单词取得同一 ASR provider 和 Session。该优化不预先生成识别结果，也不改变暂停、匹配、输入、计时、得分、奖励或历史。

## 页面自动接管

每个标签页使用独立的随机页面标识。页面打开时声明当前控制权；若另一标签页或浏览器仍连接同一场未完成游戏，服务端先保存已确认状态，再以专用 WebSocket 关闭码使旧页自动返回词库。接管只更新会话所有者和操作日志，不提交输入、不增加重试，也不改动得分、奖励或历史记录。后端测试逐字段比较接管前后的序号、得分、奖励、处理进度和历史总数；双标签页 Playwright 流程验证旧页自动退出、新页可恢复。

0.2.6 修复多个历史暂停会话并存时的遗漏：服务启动只保留最近一场为可恢复状态，当前页面发起练习时也会直接接管匹配会话或正在准备的任务；成功切换模式后，其余未完成快照标记为关闭。关闭动作保留快照和操作审计，不新增学习历史、积分、奖励或结算事件。新增浏览器回归复现“先暂停免麦克风复习、再完成普通练习、另一页面重新开始复习”的流程，确认不再出现另一浏览器冲突。

## 子弹命中与方向

旧前端在每次按键时立即画子弹，并用活动词列表最后一项作为目标，因此错键也发射，正确键也可能射向别的词。现由服务端完成字符判定后，仅在 `HitEvent` 上随确认回执返回实际命中的 `runtime_id`；错误输入和重复序号不返回命中。前端按该编号读取对应词条最后一帧的归一化画布坐标后再发射，最后一个字母使词条从状态中移除时仍能保持正确方向。浏览器回归同时验证错键零弹道，以及正确键弹道与目标词条中心在同一射线上；服务端单测验证正确目标和重放不重复发射。该变化只修正视觉反馈，不改变输入事件、计分、正确率、奖励或历史。

## 单机数据库迁移

迁移器只读打开桌面库，先检查 SQLite 完整性并计算 SHA-256；B/S 目标库先通过 SQLite backup API 备份。单机库另存完整归档后，所有转换在单一事务内执行，并写入 `migration_imports` 和逐词 ID 映射。累计总分以单机库保存的 `total_score` 原值写成带来源的迁移积分事件；累计复习时间从导入和后续生成的每日复习有效计时汇总。旧整站／整软件打开时长继续保留以便审计，但不再显示或进入新结算邮件。重复运行同一来源不会重复增加数据，来源文件变化则停止并要求重新审核。

用户确认的最新 69.82 MiB 单机库已在隔离 B/S 副本完成全量演练：来源 1,178 个词、10,846 条学习历史、1,303 条错字、134 条奖励轮次、128,174 条操作日志、95 条结算邮件事件和 3,941 条 AI 缓存全部转换成功；其中与测试 B/S 库重复的 1 个词按键合并。迁移后 SQLite `integrity_check=ok`、外键检查为空，B/S 可读取 1,181 个合并词、10,867 条历史记录、128,205 条操作日志和 97 条结算事件；以相同来源再次执行会返回 `already_imported`，不会重复累加。旧规则样本 2026-07-15 保持 99/100 分对应 ¥4.95，新规则样本 2026-09-27 保持 197/400 分对应 ¥1.97。单机未完成游戏状态保留在完整归档中，不替换 B/S 当前会话。
